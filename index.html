Privacy Policy

Last updated: November 19, 2026

SHEIKH SCIENTIFIC is a browser-based scientific calculator. Calculations run on your device. No account is required.

1. Information stored

The app keeps calculation history only for the current page session and does not save new entries to LocalStorage. If a previous version left a legacy history key in this browser, the app imports those entries into this session and leaves the legacy key untouched until you explicitly clear history. It does not ask you to provide personal profile information. Theme mode is the only app setting saved locally; Auto follows your device's light or dark appearance setting. Avoid entering sensitive information in calculations because expressions may appear in the on-screen history until it is cleared or the page is closed.

2. How information is used

Locally stored information is used only to import legacy history entries and remember your theme. New calculation history is session-only. This version has no analytics, advertising, tracking pixels, login, or app-operated server calls.

3. Information sharing

The app does not send calculations or locally stored data to an app-operated server. Your browser, device, extensions, operating system, and any hosting provider may have their own data practices.

4. Deleting your information

Use “CLEAR HISTORY” to remove the current history and, only after that explicit action, delete the legacy LocalStorage history key. Use “Clear all local data” to remove the saved theme preference and delete both current and legacy history. Closing or refreshing the page discards newly created in-memory history but does not automatically delete legacy history. Clearing this site's browser data also removes saved app data.

5. Security

The app uses a Content Security Policy and includes no third-party scripts or network APIs. LocalStorage is not encrypted; someone with access to your device or browser profile may be able to view it. Public deployments should use HTTPS and appropriate server security headers.

6. Children's privacy

The app does not require registration or request personal information. It is not designed to collect information from children.

7. Changes

This policy may be updated if the app's features or data practices change. No personal developer contact information is collected or displayed by this app.
